## 🎯 项目简介

**一人公司全能运营助手（OPC）** 是一个覆盖**内容创作、商业运营、产品研发、客户服务、个人提效**五大模块的 AI Skill，让独立创业者、自由职业者、副业达人**一个人完成原本需要 5～10 人团队才能完成的工作**。

> **核心价值**：独立创业者不再需要编辑、运营、产品、客服、助理五个专职人员。一个 AI，顶一支队伍。

## 📊 模块功能索引

### 01 · 内容创作

| 功能 | 触发方式 | 输出格式 |
|------|---------|---------|
| 月刊撰写 | "帮我做本月月刊，主题是…" | Markdown / HTML 可发布版 |
| 播客脚本 | "写一期播客脚本，话题是…" | 带时间轴的分段脚本 |
| 短视频文案 | "帮我写一条抖音文案" | 15s/30s/60s 三版 |
| SEO 文章 | "写一篇关于 XX 的 SEO 文章" | 带关键词布局的长文 |
| 电子书章节 | "帮我写《XX》的第3章" | Markdown 章节文件 |

### 02 · 商业运营

| 功能 | 触发方式 | 输出格式 |
|------|---------|---------|
| 品牌 Slogan | "帮我提炼品牌标语" | 5 个候选 Slogan |
| 朋友圈推广 | "帮我做一条朋友圈推广文案" | 图文搭配文案 |
| 邮件营销 | "帮我写一封产品发布邮件" | HTML 邮件模板 |
| 广告投放方案 | "帮我做小红书信息流投放方案" | 投放策略文档 |
| 竞品分析 | "帮我分析 XX 的竞品" | 竞品对比报告 |

### 03 · 产品研发

| 功能 | 触发方式 | 输出格式 |
|------|---------|---------|
| 用户反馈表单 | "帮我设计一个用户反馈收集表单" | HTML / Typeform 格式 |
| 数据看板 | "帮我设计 SaaS 核心指标看板" | 指标定义 + SQL 查询示例 |
| 产品路线图 | "帮我规划 Q3 产品路线图" | 优先级排序的 Feature 列表 |
| PRD 撰写 | "帮我写 XX 功能的 PRD" | 标准 PRD 文档 |
| 用户画像 | "帮我做目标用户的 Persona" | 3-5 个典型用户画像 |

### 04 · 客户服务

| 功能 | 触发方式 | 输出格式 |
|------|---------|---------|
| 客服回复模板 | "有客户问退款政策，帮我写回复" | 多情境话术模板 |
| 7×24 自动回复 | "帮我设置自动回复话术" | 常见问题 FAQ + 自动回复 |
| 退款/投诉处理 | "客户投诉 XX，帮我写处理方案" | 处理流程 + 话术 |
| 社群管理文案 | "帮我写社群早报/晚报" | 社群运营文案 |
| NPS 调研 | "帮我设计 NPS 调研问卷" | 问卷 + 分析框架 |

### 05 · 个人提效

## 🚀 快速开始

### 作为 AI Skill 使用（推荐）

将本仓库放入 AI Agent 的 Skills 目录，直接发送需求即可：

```
"帮我写这个月的博客月刊，主题是 AI 工具盘点"
"我有一家 Shopify 店铺，帮我做一条朋友圈推广文案"
"帮我设计一个用户反馈收集表单，给我的 SaaS 产品用"
"有客户问退款政策，帮我写一份客服回复模板"
"帮我整理今天的 GTD 清单，有 8 件事要做"
```

### 输出原则

- ✅ **直接给可执行的成品内容**，不说废话
- ✅ **格式清晰美观**，可直接复制使用
- ✅ **信息不足时，先给最优假设版本再询问调整**
- ✅ **识别边界**：超出能力范围的请求主动说明并引导替代方案
